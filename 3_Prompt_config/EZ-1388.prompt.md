# Manual Test Case Generation Prompt
 
 
 
## Execution Workflow
 
 
 
When this prompt is executed, follow these steps:
 
 
 
### Step 1: Prompt for User Story Path
 
Ask the user:
 
```
 
Please provide the User Story file path : /workspaces/testcase1/1_Base_Repo/User_Story/EZ-1388.doc
 
Path for csv file should be same as user story file path with changes in folder and file name like below: /workspaces/testcase1/1_Base_Repo/User_Story/EZ-1388 logic .csv
 
```
 
 
 
### Step 2: Generate Test Cases and Save CSV File
 
- For each acceptance criterion/scenario in the user story, generate one test case
 
- Create a CSV file with proper structure and multi-line cell formatting (wrap in double quotes)
 
- Number actions sequentially (1., 2., 3., etc.) with line breaks between steps
 
- Write expected results as continuous text WITHOUT numbering
 
- Automatically save the CSV file to: `/workspaces/testcase1/4_Design_Studio/{filename}_TestCases.csv`
 
- Confirm completion with message:
 
```
 
Test cases generated successfully!
 
Output file: /workspaces/testcase1/4_Design_Studio/{filename}_TestCases.csv
Total test cases: {count}
 
```

## Important Notes
 
1. Generate exactly one test case per acceptance criterion in the user story
 
2. For information screen , generate test cases for all 4 sceneriors as per the logic excel.
 
3. Include only relevant navigation steps based on the specific scenario scope  
 
4. Keep test cases atomic and focused on specific scenario validation
 
5. Ensure proper CSV escaping for special characters and multi-line cells (use double quotes)
 
6. Number actions sequentially (1., 2., 3., etc.) with line breaks between steps
 
7. Write expected results as continuous text WITHOUT numbering, separated by line breaks
 
8. Reference navigation_steps_ips_1388.md for accurate EZDOCS workflow patterns
 
9. Use Template_ips_1388.md structure for field mapping and test case structure (reference only, not copy values)
 
10. Use forward slashes (/) consistently in all file paths
 
11. Extract filename from user story path correctly for output file naming (e.g., EZ-1388.doc → EZ-1388)

## Output Format: CSV Structure
 
 
 
**CSV Headers:**
 
```
 
TC ID,Test type,Test case Name,Description,Actions,Expected Results,Test Repository Path,Status,User story,Priority
 
```
 
 
 
**CSV Format Rules:**
 
1. Each test case is a single row in the CSV
 
2. Wrap multi-line cells (Actions and Expected Results) in double quotes
 
3. Escape commas within fields using double quotes
 
4. Escape double quotes within fields by doubling them ("")
 
5. Number actions sequentially (1., 2., 3., etc.)
 
6. Expected results should NOT have numbering - keep as plain text
 
7. Use actual line breaks within quoted cells or \n for separating action steps
 
 
 
**Example CSV Output:**
 
```csv
 
TC ID,Test type,Test case Name,Description,Actions,Expected Results,Test Repository Path,Status,User story,Priority
 
 
```
